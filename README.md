# Dell Wyse 3040 USB/IP Server

Dell Wyse 3040を、USB機器をネットワーク経由で使えるデバイスサーバーにする管理ソフトです。DebianのUSB/IPに、自動共有・Web管理・本体コンソール・設定保存を組み合わせています。

小型PCやRaspberry Piなどへ同様の仕組みを移植するため、現在のソースと構成を公開しています。**現行コードはWyse 3040／Debian 13 amd64向けです。Raspberry Pi対応済みのソフトや完成済みOSイメージではありません。**

## 機能

| 機能 | 内容 |
| --- | --- |
| USB自動共有 | USBを挿すと自動で共有。HIDを含む機器、ハブ、本体でマウント中のストレージは除外 |
| 共有の管理 | 機器名・バスID・状態を表示。機器ごとの一時停止、再開、エラー状態からの復旧 |
| 接続履歴 | RAM上に最大200件。本体の再起動で消去 |
| システム状態 | OS・カーネル・管理ソフト版、IP、SSID、稼働時間、RAM、サービス状態 |
| ネットワーク設定 | 有線IPv4のDHCP／固定、ゲートウェイ、DNS、Wi-Fi親機のSSID・認証、ホスト名 |
| 設定の試用 | 有線・Wi-Fi変更後120秒以内に確定。未確定なら元に戻す |
| 本体メニュー | 矢印キー操作。単独／既存LANモードは最後に確定した設定を次回も使用 |
| 管理認証 | 設定画面のみHTTPS認証。Webでパスワード変更、本体コンソールで再発行 |
| OS保護 | OverlayFSの書き込み先をRAMへ。設定は別ext4領域へ保存 |
| OS更新 | WebからAPTでOS・カーネル更新。保護解除の保守起動と保護復帰を管理 |

単独モードはWi-Fi親機とDHCP配布を有効にします。既存LANモードは親機と本機のDHCP配布を停止します。有線のDHCP取得／固定IPは別の設定です。無線LANへの子機接続を切り替える汎用ルーター管理ソフトではありません。

## Web画面

| パス | 用途 | 認証 |
| --- | --- | --- |
| `/` | システム状態へ移動 | 不要 |
| `/system.py` | システム状態 | 不要 |
| `/usbip.py` | USB共有一覧・接続履歴 | 不要 |
| `/network.py` | 設定・共有操作・OS更新 | HTTPS、ユーザー名 `admin` |

HTTPは80番、HTTPSは443番、USB/IPはTCP 3240です。ホスト名を `wyse-usbip` に設定した場合の入口は `https://wyse-usbip.local/` です。初期管理パスワードはセットアップ時にランダム発行します。共通の固定パスワードはありません。

本ソフトのHTTPS認証は管理画面用です。USB/IP転送そのものに認証・暗号化・ペアリングを追加する実装ではなく、信頼できるLANでの利用を前提とします。USB/IPクライアントは別途必要です。

## 対象ハードウェア

| 項目 | Wyse 3040の構成 |
| --- | --- |
| CPU | Intel Atom x5-Z8350、4コア、基本1.44 GHz／最大1.92 GHz |
| メモリ | 2 GB DDR3L-1600 |
| ストレージ | eMMC。本資料は8 GB構成を想定 |
| 有線LAN | ギガビットEthernet |
| 無線LAN | オプション。対象構成はAW-CM389MA／Marvell 8897、SDIO接続 |
| USB | USB 3.0 ×1、USB 2.0 ×3 |
| 映像出力 | DisplayPort ×2 |

公称仕様：[Dell System specifications](https://www.dell.com/support/manuals/ja-jp/wyse-3040-thin-client/3040_ug/system-specifications?guid=guid-b35dd1df-32f3-4c36-84a9-52d9a5c0810c&lang=en-us)。無線の有無やストレージ容量は手元の個体を確認してください。

## 制約

- 一つのUSB機器を複数クライアントが同時使用する仕組みではありません。
- 自動共有はサーバー側の処理です。クライアントの自動接続・再接続は別途必要です。
- 接続履歴は0.5秒ごとの監視で、短時間の変化を取りこぼす場合があります。
- OS保護でも設定領域への書き込みは発生します。電源断による破損を完全に防ぐものではありません。
- APT更新は管理ソフト自身やDebianのメジャー版を更新しません。パッケージの自動ロールバックも行いません。
